# 📈 부동산 vs 주식 투자 수익률 비교 대시보드

KB부동산의 '월간 아파트 매매가격지수'와 국내외 대표 주가지수(KOSPI, S&P 500)의 장기 시계열 데이터를 결합하여, **1986년 1월부터 현재까지** 부동산과 주식의 장기 누적 수익률을 직관적으로 비교 분석할 수 있는 Streamlit 인터랙티브 웹 대시보드입니다.

---

## 🌟 주요 기능

1. **조회 기간 설정 & 빠른 선택**:
   - **달력 캘린더**: 시작일과 종료일을 자유롭게 설정 가능 (1986년 1월 ~ 최신 발표월).
   - **빠른 선택 (Quick Select)**: `1Y`, `5Y`, `10Y`, `20Y`, `MAX` 버튼 클릭 시 캘린더와 차트가 즉시 동기화.
   - **Update 버튼**: `KBData/` 폴더 내 최신 KB 엑셀 파일 및 최신 주식 데이터를 원클릭으로 재동기화.
   - **새 KB 엑셀 업로드 드롭존**: 웹 화면에서 새 월간 엑셀 파일을 드래그 앤 드롭하여 즉시 업로드 및 갱신.

2. **6대 대표 지표 꺾은선 차트 (Plotly)**:
   - **지표**: 강남11개구, 강북14개구, 수도권, 전국, KOSPI, S&P 500
   - **0% 기준 정규화 누적 수익률**: 조회 시작월을 `0.0%`로 정규화하여 이후 시점의 누적 수익률(%)을 비교.
   - **인터랙티브 툴팁**: 일자 헤더 아래 각 지표명, 누적 수익률(소수점 2자리 고정), 원본 지수/종가를 일목요연하게 표시.
   - **스파이크라인 가이드라인, 0% 기준선, 범례 토글** 지원.

3. **투자 성과 비교 분석 & 데이터 다운로드**:
   - **누적 수익률 KPI 카드**: 6개 지표의 최종 수익률과 CAGR(연평균 복리 수익률) 한눈에 확인.
   - **투자 성과 비교 분석표**: 시작값, 최종값, 누적 수익률(%), CAGR(%), MDD(최대 낙폭 %), 월간 최대 상승/하락률 종합 비교.
   - **CSV & 다중 시트 엑셀 다운로드**: 가공된 수익률 데이터, 성과 비교표, 원본 지수 종가를 CSV 및 엑셀(`.xlsx`)로 다운로드.

## 🚀 실행 방법

### Windows (원클릭 실행)
`run_app.bat` 파일을 더블클릭하면 가상환경 및 의존성을 자동으로 확인한 후 웹 브라우저가 실행됩니다.

### 수동 실행 (CLI)
```bash
pip install -r requirements.txt
streamlit run app.py
```
브라우저 접속 주소: `http://localhost:8501`
